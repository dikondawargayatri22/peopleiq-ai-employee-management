# PeopleIQ — AI Integrated Employee Management System

PeopleIQ is an AI-powered employee management dashboard designed for HR teams, managers, and company admins.

The system helps manage employees, attendance, leave requests, performance reviews, payroll summaries, recruitment, onboarding, and AI-powered workforce insights.

## Project Goal

To build a modern full-stack HR management platform using React, Spring Boot, PostgreSQL, and AI integration.

## Key Features

- Employee Management
- Attendance Tracking
- Leave Management
- Performance Review
- Payroll Summary
- Recruitment Pipeline
- Onboarding Checklist
- AI HR Assistant
- AI Attendance Anomaly Detection
- AI Attrition Risk Insights
- AI Performance Summary
- Role-Based Access Control
